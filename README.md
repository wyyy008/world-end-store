# 《世界尽头的便利店》

八夜首章是一款可离线游玩的浏览器游戏。下载并解压试玩包，打开 `index.html`，点“推门进去”开始。进度保存在当前浏览器，可在设置中导出并导入。

## V4.0 第一夜场景探索

第一夜从雾港货架开始。画面边上的任务栏显示正在做的事、已完成的步骤和“下一步”按钮。按价签摆回三件商品，接待阿澄，再把拿到的物证带往收银台和监控室。店门与柜台下的包裹也可以随时查看。背包保存实物，线索册记录发现，任务栏在停滞 30、60、90 秒时逐级提示。翻看物件、解谜和走动都不减少营业时间。

查清 00:17 的录像后，收银机会出现“未寄出的信”。对这笔交易的处理、第三次门铃的回应和打烊留物都会留在存档里。第二夜根据选定路线在无眠车站或倒着走的夏天开场。正在进行的旧存档仍从原有夜次、交易或阅读位置继续。

场景与道具逻辑在 `scene-manager.js`，场景布局在 `exploration.css`。章节过场由 `chapter-transition.js`、`chapter-transition.css` 和 `audio.js` 播放；`game.js` 负责人物剧情、经营、收班和存档。

[第一夜 V4.0 改版路径与测试结果](./FIRST_NIGHT_V4.md)记录了各场景、文件和可重复的验收要点。

## 已确定的方向

- 体验基调：温柔治愈，接待奇怪但可爱的客人。
- 玩家身份：身份未知的便利店店主。
- 故事表达：主要通过商品交易、顾客行为和细小变化来呈现，不做大量对话选项。
- 核心红线：不做普通商品买卖模拟和好感度累加；所有玩法必须围绕顾客行为、商品用途变化和打烊时留下什么。
- 时间压力：每天有营业结束时间；经营行动消耗时间，阅读和思考时暂停。
- 失败处理：没有传统 Game Over，错过、迷路和资源不足会把故事导向另一条路线。
- 平台：浏览器优先，完成后再打包 Windows。
- 制作规模：当前试玩版目标 25–40 分钟；商业正式版目标为三至四章、单周目 2.5–3.5 小时。
- 开发方式：已加入原创手绘场景与人物立绘，继续用可玩性验证决定后续美术量。

## 一句话卖点

你经营一家不断穿越世界的便利店，用普通商品参与陌生客人的人生，并在每次离开前决定带走什么、留下什么。

## 当前建议

第一版采用浏览器技术与数据驱动结构：界面和交互可直接在浏览器运行，经营选择与阅读位置会自动保存在本地；玩法验证后再打包为 Windows 程序。这样你不需要学习代码，也不需要承受复杂游戏引擎带来的额外工作量。

## 2026-11-09 第一夜沉浸式改版

- 开场直接由玩家操作第一笔收银：点场景中的三件商品，找零，收起印着明日日期的异常小票；错误找零可重试。
- 阿澄接着进入主线。她离开后，玩家可主动查看收据、监控、站牌与伞，至少找到两条线索再面对第三次门铃。
- 门口的三种做法会分别出现即时回应，并写入记忆册和打烊收据；监控线索解锁额外选项。
- 第一夜聚焦柜台与任务提示。完成门铃事件后，原有货架、时间、打烊事项以及后七夜继续衔接。
- 新增雨夜柜台、路边、车站、夏天、隧道等手绘场景，以及三件商品的收银特写和第三位来客的高潮画面。

## 2026-11-08 试玩完善

- 首屏“接下来”给出当前唯一建议动作，可直接接待、回应、打烊或查看下一站，不必自己在货架和任务之间猜。
- 选择后切换到角色回应、小动作和物件变化，读完再继续；结果页也支持刷新续读，恢复时不会重复扣库存或收钱。
- 人物回忆改为主线自动穿插，随三次接待逐段展开，读完回到当前柜台；人物档案只回看已经历的完整片段。
- 五位核心人物的欲望、缺点、手艺、说话习惯与变化进入实际接待；六位配角也有独立来意和回应，普通交易结束后可以停下来听完。
- 序章逐句、每夜开场、人物过去和终章支持断点续读；刷新后不会跳过终章。对话历史随存档保留。
- 设置中增加“旅途存档”：下载 JSON 备份，导入前预览夜数与记忆，确认后才替换当前进度。可在不同设备之间手动接续。
- 保持旧版 v5 存档兼容；无效存档不会自动覆盖。浏览器保存失败会显示提示，并可下载当前内存中的旅途。
- 所有重开入口增加确认，取消后保留当前收据与进度。
- 末夜选择对应不同人物结局：沈伯当乘客、旅人坐下休息、阿澄把伞留给下一场雨，终章和收据都会如实呈现。
- 已归还的伞、围巾与已喝完的咖啡，不再被后续客人当成仍留在店里的物件。
- 新增文字“即显”，适用于序章、人物过去和终章；长按空格不再连续跳过剧情。
- 修正夏天第三夜目标提示、第四夜插曲刷新恢复，以及手机人物过去与终章的全屏布局。

## 可玩首章

双击 `打开游戏.cmd` 会自动启动本地服务并打开游戏。直接打开 `index.html` 也能运行，但浏览器可能拒绝加载本地字体。

这一版已经实现：

- 完整八夜流程，包含两条前三夜分支，以及共同的后五夜。
- 入场标题页、新游戏、继续游戏、当前存档夜数与玩法说明。
- 新游戏用两句开场交代雾港夜班，随后立即进入可操作的第一笔收银；旧存档中的序章仍可继续读完。
- 常客交易与特殊选择也使用同一套视觉小说舞台，不再以普通业务弹窗呈现。
- 序章与柜台对话都按短句逐句推进，不再整段刷屏，节奏更适合阅读。
- 视觉小说自带对话历史（backlog），玩家随时回看说过的话与做过的重要选择。
- 最后一夜五位角色的收束选择会当场得到一句符合各自语气的回应；低价与高价也不再共用同一句台词。
- 侧栏“人物”档案记录已认识的客人、在等什么与留下的东西；完整往事会随着主线逐段展开，包裹里的信在拆包后呈现。
- 剧情文字逐字淡入，并按标点和省略号调整停顿节奏；句子读完会出现继续标记。
- 第 3 夜两条路线各有一段跨路线短场；第 4 夜加入修伞的老人，第 6 夜加入卖花的女孩和找猫的人，单周目至少可见 8 张面孔。
- 第 2 夜两位常客会同时站在柜台前，先接待谁会让另一个人的开场台词发生变化。
- 第 4 夜在第一位客人离开后会触发“路边的第二盏灯”长场景，夜里多出一段不耗时间的公路事件。
- 第 5 夜会有“投币口里没有名字”的售货机小票事件，第 7 夜会有“夏天多出来的一分钟”的夕阳停顿。
- 第 6 夜按路线分成两个版本：无眠车站版围绕停摆的钟，倒着走的夏天版围绕最后一束花、红围巾和夕阳。
- 八夜中第 2、4、5、6、7、8 夜各自有不同的节奏，不再全部是“到店、接客、打烊”的同一形状。
- 最后一夜选择拆包或封存后会进入一段完整的视觉小说终章：第一班车进站、五个人逐一收束、总体结局、店继续上路。
- 收据会把五个人的单独结局完整列出，并区分“走出等待”和“仍保留遗憾”；可以重看终章。
- 除第一夜外，每进入新的一夜会先播一段视觉小说开场：包裹里的某一页认出第一个客人，客人说出自己在等什么。
- 柜台、交易舞台和终章都使用同一套五人剪影肖像；阿澄的伞、沈伯的帽檐、0217 的工牌、小满的饭盒和旅人的兜帽是各自的识别点。
- 第一夜从收银机的小票逐步带出五封未寄出的信和不断漂移的便利店。
- 五位常客会开始提到彼此：小满知道沈伯的咖啡，沈伯知道小满的天气，卖花女孩与找猫的人也带着前一位客人的线索。
- 人物档案新增“说话方式”，把阿澄的“等与伞”、沈伯的“班次与时刻”、0217 的“排班与编号”、小满的“天气与饭”、旅人的“地址与收件人”固定下来。
- 留下的东西会在后面的客人场景里被看见；断伞、白花和盐粒小路也会成为新的打烊留下物。
- 拆包结局会按实际收束人数显示完整版或“只读完一部分”；包裹里的信只有在真正拆包后才会在人物档案中解锁。
- 第八夜的“把包裹放上柜台”不耗时间，给五场收束留出一格容错。
- 音效与氛围使用浏览器原生音频合成，包含点击、翻页、硬币、门铃、成就、错误提示、雨声和低频旋律，不依赖外部音频版权。
- 设置面板可调整总音量、音乐与氛围、音效、静音和文字速度，并自动保存在本机；序章中也能直接打开。
- 主界面改成夜间舞台：六盏灯是时间条，柜台是主画面，右侧像一本店务账本；不再用大块白色 KPI 卡片和横向表格。
- 标题页去掉路线清单，改成雨夜店窗、柜台和包裹的封面；主按钮是“推门进去”。
- 阿澄、沈伯、0217、小满和无名旅人五位反复出现的客人，各有独立支线与最终答案。
- 十二条商品与地点用途，包括旧收音机、红围巾、玻璃汽水瓶和过期车票。
- 四个正常地点和一个迷失地点：雾港公交站、无眠车站、倒着走的夏天、自动售货机隧道和无名公路。
- 现金、库存、车票、顾客状态和记忆跨夜保留。
- 首次进入时有包裹开场，主界面持续显示最终目标与剩余夜数。
- 六个营业时间格、货架直补、整理小事与三档定价。
- 不再预告后面会来的客人；侧栏只保留柜台前当前的人。
- 每夜都有通行条件，达成后才会从特殊渠道得到一张车票；没有车票也能走，但店会被动漂移并损失 ¥5。
- 每夜小事不是装饰：它既能达成通行条件，也会在后面的夜里打开新的回应，例如第一夜整理过的饭盒会在夏天等到小满。
- 最后一夜也必须先把包裹放上柜台，才能选择拆开它；否则只能重新封存。
- 时间用完后仍可接待柜台前的客人，不会自动把玩家赶去结算。
- 打烊纪念物选择、营业收据和本地自动存档。
- 五人不是血亲、最终可以选择成为家人的首章主线。
- 两种收束：拆开包裹或重新封存。结局不标注 HE/BE，而是一起呈现五个人各自保留的遗憾与回答。
- 完整收据、人物支线进度和章节重开。
- 桌面、平板和手机布局。

阅读、打开对话框和查看记忆册都不消耗营业时间。点击“重新营业”会清除本地进度。

## 当前操作

- 顶部目标始终显示“让没有收件人的包裹找到去处”和第一班车倒计时。
- 柜台前有人时可直接接待；货架和整理小事仍可先做，但花掉的时间会影响接下来还能照顾谁。
- 柜台缺货时，对话里会直接出现“补到够用”，不用退出后重新点客人。
- 提前打烊会先提醒还没接待的人；坚持打烊也会把这件事写进当晚收据。

## 界面文件

- `index.html`：界面结构。
- `styles.css`：视觉、响应式布局和交互状态。
- `content.js`：十二件商品、八夜顾客、路线、任务和结局文本。
- `audio.js`：音效合成、雨声氛围、背景旋律与音量控制。
- `game.js`：顾客、时间、库存、跨夜推进、存档和结局逻辑。
- `server.js`：双击启动器使用的本地静态服务，无第三方依赖。
- `ui-direction.md`：本版界面设计方向与取舍。
