# 游戏质量验证

先阅读 README.md 的启动说明与现有测试脚本，使用项目原有启动方式；不假设存在 npm 或 Playwright。

## 最小回归测试
1. 新游戏 → 第一夜三件商品 → 找零失败重试 → 正确完成。
2. 查看未来日期小票 → 阿澄剧情 → 收据/监控/站牌/伞线索 → 第三次门铃。
3. 行动时间正确变化；阅读对话不扣行动。
4. 刷新继续游戏不重复扣钱、扣库存、发放线索或跳过剧情。
5. 新存档与旧存档读取；无效导入不会覆盖现有进度。
6. PC 鼠标与键盘、手机触摸与竖屏；对话框不挡关键按钮。
7. 动画期间连续点击、快速切换、重复打开关闭弹层。
8. 音效静音、资源缺失、浏览器本地存储失败时有合理退化。

## 输出格式
- 已执行测试：具体步骤与结果。
- 未执行测试：原因，不要声称已通过。
- 问题：复现步骤、预期/实际、影响、相关文件。
- 修复后重新测试原问题及相邻流程。

仅在环境支持时使用浏览器自动化或截图；不可用时给出人工测试步骤。
